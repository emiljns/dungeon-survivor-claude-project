The sprite sheets used are copied into `public/assets/ninja/` under
shorter names, unmodified except `tiles-floor-outdoor.png`
(TilesetFloor.png), whose stray last pixel row is cropped (417 to 416 px)
so it divides into 16 px tiles. `src/data/artManifest.ts` records the
original path of each one inside the pack.

The game's original placeholder art, lighting textures and UI are
generated in code (`src/rendering/`).
